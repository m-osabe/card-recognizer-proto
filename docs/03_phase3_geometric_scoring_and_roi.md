## 3. 解明された2大根本原因と知見

### 知見 1: `card-6` と `card-7` のマスター間共通枠問題（同型カード）
- **現象**: `card_06` のテスト写真（`card_06_xxxx.jpg`）の大部分が `card-7` に誤判定される。
- **根本原因**: マスター画像 `card-6.jpg` と `card-7.jpg` を直接照合したところ、**外枠・背景装飾だけで 75点 もの特徴点が共通一致**していました。
- **重要な技術的知見**:
  TCGカードにおいて、同一シリーズ・同一レアリティのカードは「外枠（ボーダー）」がほぼ同一であるため、**「外枠の特徴点はカード識別においてノイズ（無価値）」**であり、**「イラスト中央領域（$y: 13\% \sim 63\%$）およびカード名タイトル領域（$y: 4\% \sim 13\%$）の特徴点のみが唯一の識別根拠である」**という点です。

### 知見 2: `card-10` の暗所写真における幾何妥当性判定の過度な厳格さ
- **現象**: `card_10` の写真群（`card_10_xxxx.jpg`）でスコアが急落し、`[NG] MISS` や別カードに判定される。
- **根本原因**: `card_10` のテスト写真群は撮影環境の照明が暗く、低コントラストによる微細な位置ズレが発生していました。RANSACの再投影誤差閾値（3.5px）が暗所ブレ写真に対して厳格すぎたため、正解の `card-10` の変換行列が「幾何妥当性なし（`is_geom_valid = False`）」と判定されて減点されていました。

## 4. Phase 3.1 改善策の実装内容

### ① 空間ROI重み付けの超強化（`matcher_sift.py`）
外枠の共通特徴点（75点）の影響を完全に断ち切るため、インライアの座標空間判定を以下のように強化：

```python
# イラスト固有領域・タイトル領域への重み集中
if 0.13 * h_m <= y <= 0.63 * h_m:
    ill_inliers += 1    # 重み 4.0倍
elif 0.04 * h_m <= y < 0.13 * h_m:
    title_inliers += 1  # 重み 2.5倍
else:
    common_inliers += 1 # 重み 0.05倍 (外枠ノイズをほぼゼロ化)

effective_inliers = (ill_inliers * 4.0) + (title_inliers * 2.5) + (common_inliers * 0.05)
```

### ② 暗所適応型 RANSAC 幾何検証（`matcher_sift.py`）
マッチング点数に応じて RANSAC の再投影許容誤差を動的に調整：
- マッチ数 $\ge 15$: 許容誤差 **3.5px**（高精度幾何検証）
- マッチ数 $< 15$（暗所・ブレ写真）: 許容誤差 **4.5px**（柔軟な救済）

### ③ 低インライア時のハイブリッド SIFT 補完フォールバック（`card_engine.py`）
正面切り出し画像でインライアが 8点未満 の場合、元写真全体からも特徴点を補完照合。
