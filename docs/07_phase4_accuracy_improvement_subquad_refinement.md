# 複合輪郭からの長方形探索およびコーナー精緻化 (Phase 4.3) の実装・検証結果

手持ち撮影時（`card_10_0008`, `0009` 等）に発生していた「カードと手・腕のエッジ合体」による検出失敗、および「指のふくらみ」を角として誤認識していた問題を解決しました。

---

## 1. 実施した改善内容

### (1) 複合輪郭からの長方形サブセット探索 (Stage 4)
- **ファイル**: [`card_detector.py`](file:///C:/Users/mbs0373/.gemini/antigravity/scratch/card-recognizer/card_detector.py)
- **内容**:
  - Canny、適応的二値化、Otsu 二値化の各ステージ（Stage 1〜3）で独立した4頂点四角形が見つからなかった場合のフォールバックとして `_find_sub_quadrilateral` を新設。
  - 手や腕が合体した大きな多角形輪郭（15〜25頂点）から、直交性（内角誤差 $\le 14^\circ$）、対向辺の平行度、アスペクト比（$1.20 \le \text{asp} \le 1.65$）、面積比率を満たすベストな4頂点コンビネーションを探索。
  - **幾何学的正則化（Parallelogram Regularization）**: 指のふくらみ（$x=487$）によって 1 点だけ外側に突き出している頂点を、他3点の直交ベクトルから平行四辺形補完で真の角位置へと吸着補正。

### (2) SIFT幾何ホモグラフィによる四隅のピクセル精度精緻化
- **ファイル**: [`card_engine.py`](file:///C:/Users/mbs0373/.gemini/antigravity/scratch/card-recognizer/card_engine.py)
- **内容**:
  - 切り出したカード画像で SIFT 照合を行い、十分な幾何インライア（$\ge 8$）が得られた場合に、マスターカードの真の四隅 $[(0,0), (W,0), (W,H), (0,H)]$ をホモグラフィ逆行列 $H^{-1}$ によって逆投影。
  - 指の裏に隠れているカード本来の角をサブピクセル精度で再計算し、微小な切り出しズレを完全解消。
