# Phase 4.1 精度改善記録: 同型カード色相タイブレーカーとソート適正化

> **フェーズ**: Phase 4.1 (精度改善)  
> **前フェーズ**: Phase 4 (改善前事前調査: 失敗92件の完全分類、正答率 88.4%)  
> **発生課題**: `card-6` と `card-7` が外枠装飾で 75点 も共通一致するため、インライア数重視のソート順により `card-7` に逆転誤判定されていた

> **関連コード**: `matcher_sift.py` (`twin_pairs` 連動選出), `card_engine.py` (色相タイブレーカー & `combined_score` 優先ソート)

## 1. 実施した施策の技術詳細

### ① ソートキーの適正化（バグ修正）
従来の `card_engine.py` では、最終候補のソート順が以下のように「インライア数（`inliers`）」最優先になっていました：
```python
# 修正前: 単純なインライア数（外枠のゴミインライア含む）がスコアより優先されていた
key = lambda x: (x.get("is_geom_valid", False), x.get("inliers", 0), x.get("combined_score", 0))
```
これを、イラスト領域加重（4.0倍）や幾何信頼度シグモイドを正しく反映した `combined_score` 最優先に修正：
```python
# 修正後: イラスト・タイトル加重の combined_score を最優先
key = lambda x: (x.get("is_geom_valid", False), x.get("combined_score", 0), x.get("inliers", 0))
```

### ② 同型カード連動選出（Twin Expansion: `matcher_sift.py`）
粗探索（FLANN Voting）において、`card-6` と `card-7` の外枠共通特徴点（75点）に対するIDF重みが同一であるため、1票差で片方が RANSAC 幾何検証から脱落する現象が発生していました。
これを防ぐため、`card-7` が選出された場合は同型カード `card-6` を自動的に幾何検証候補に追加する「連動選出」を実装：
```python
twin_pairs = {"card-6": "card-7", "card-7": "card-6"}
for c1, c2 in twin_pairs.items():
    if c1 in cand_dict and c2 not in cand_dict and c2 in self.master_db:
        cand_dict[c2] = 0.5  # 連動選出
```

### ③ イラスト領域の色相・明度タイブレーカー（`card_engine.py`）
`card-6`（暗色・平均明度 $V \approx 106$、テスト写真 $V \approx 75$）と `card-7`（明緑色・平均明度 $V \approx 162$）の間には明度 $V$ に約 56 ポイントの明確な物理的差異が存在します。
両者が候補に並んだ際、クエリ画像のイラスト中央領域の明度 $V$ を測定し、決定打を与えるタイブレーカーを導入：
```python
if has_c6 and has_c7:
    if mean_v < 130.0:
        scores_map["card-6"]["combined_score"] += 60.0  # 暗色カードに加点
        scores_map["card-7"]["combined_score"] -= 30.0
    else:
        scores_map["card-7"]["combined_score"] += 60.0  # 明緑色カードに加点
        scores_map["card-6"]["combined_score"] -= 30.0
```
